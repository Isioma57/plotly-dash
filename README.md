# Global Superstore Dash App

This folder contains the standalone version of the Global Superstore dashboard.

## Files

- `app.py`: data preparation, layout, charts and callbacks
- `data/superstore_sales.xlsx`: source workbook
- `requirements.txt`: Python dependencies
- `Procfile`: production start command

## Run locally

```bash
python -m pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:8050` in a browser.
